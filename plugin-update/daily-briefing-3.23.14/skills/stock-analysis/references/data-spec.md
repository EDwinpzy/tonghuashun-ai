# 数据采集规范

## 执行命令

```bash
python {skill_dir}/scripts/fetch_stock_data.py {股票名称或代码}
```

脚本一次性获取全部数据，输出JSON文件路径到stdout最后一行（文件名含股票代码避免缓存污染），进度输出到stderr。

## JSON数据结构

| Key | 内容 | 说明 |
|-----|------|------|
| `quote` | 实时行情 | 价格/涨幅/市值/换手率/主力净流入等 |
| `finance_raw` | 财务数据 | wencai 4年数据；NaN→"暂无"（key保留） |
| `finance_columns` | 财务列名 | 供映射列名到指标 |
| `peers_raw` | 同业对比 | 基于行业末级分类动态查询 |
| `holders_raw` | 股东数据 | 十大流通股东/北向/机构；NaN→"暂无" |
| `holders_parsed` | 股东名称列表 | `\|\|`分隔字符串已解析为列表 |
| `big_orders` | 大单流向 | 10条，时间可读，方向中文（附direction_legend） |
| `news` | 近期新闻 | 15条（ths.news空时回退wencai） |
| `product_raw` | 产品结构 | 拆分2次wencai查询提高命中率 |
| `chip_structure` | 筹码结构 | 5子项预填充空dict，不缺key |
| `blogger_opinions` | 博主观点 | 淘股吧→雪球→Serenity(X)，含sources |
| `barrier_data` | 壁垒数据 | 研发/专利 + 市场地位 |
| `research_reports` | 机构研报 | 东方财富+研报客双源 |
| `elapsed_seconds` | 采集耗时 | 通常8-15秒 |

## wencai列名映射

列名格式：`指标名[日期]`，如 `营业收入[20251231]`

| 报告需要 | wencai列名模式 | 转换规则 |
|----------|---------------|----------|
| 营收 | `营业收入[YYYYMMDD]` | 元→÷1e8→亿元 |
| 归母净利 | `归属于母公司所有者的净利润[YYYYMMDD]` | 元→÷1e8→亿元 |
| ROE | `净资产收益率roe(加权,公布值)[YYYYMMDD]` | 直接使用(%) |
| 毛利率 | `销售毛利率[YYYYMMDD]` | 直接使用(%) |
| 负债率 | `资产负债率[YYYYMMDD]` | 直接使用(%) |
| 公司全称 | `公司中文名称` | 字符串 |
| 实控人 | `实际控制人[YYYYMMDD]` | 字符串 |
| 行业 | `所属同花顺行业` | 字符串 |

## 补充数据（可选，最多2次WebFetch）

thsdk无法获取的数据用WebFetch补充（30秒超时，失败跳过）：
- 公告原文/异动详情、研报目标价
- **客户供应链细节**（年报前五大客户名称及收入占比、中标公告客户）
- 估值历史分位数

数据缺失标注"暂无"，禁止编造。

## 数据铁律

1. 财务数据 → thsdk wencai_nlp（主）+ WebFetch（辅），数字标注来源年份
2. 消息面 → thsdk news + 公告列表，禁止编造
3. 客户关系 → 🟢=公告/年报确认 ⚠️=推测。每行产品须≥1个已知客户名称+占比
4. 估值数据 → thsdk + wencai，历史分位须注明区间
5. 预期差 → 市场共识 vs 实际可能 + 验证节点
6. 不可追溯数据 → 标注 `[未证实]`
7. 时效性 → 用最新已披露报告，预测值标注 `[预测]`

## 容错机制

| 场景 | 处理方式 |
|------|----------|
| thsdk脚本执行失败 | WebFetch补充关键数据，最多3次 |
| thsdk连接超时 | 等30秒重试1次，仍失败则WebFetch降级 |
| 部分数据缺失 | 保留已有数据，缺失项标注"暂无" |
| 关键数据（股价/市值）缺失 | 告知用户"数据不足，请稍后重试" |
| WebFetch失败 | 跳过继续 |
| ths.news返回空 | 自动回退wencai查询 |
| 产品数据wencai查询空 | 拆分2次查询提高命中率 |
| 博主缓存不存在 | ①直接爬取 ②Serenity搜索 ③标注暂无 |
| 同业对比无行业信息 | 降级为仅查询目标股票自身 |
| 研报数据为空 | 标注"暂无机构覆盖"，不编造 |
