# 评分框架

## 壁垒量化分析（六维，0-30分）

基于 `barrier_data` + `finance_raw` + `peers_raw` 评分：

| 维度 | 分值 | 5分条件 | 0分条件 |
|------|------|---------|---------|
| ① 技术壁垒 | 0-5 | 研发比>5% + 专利>同行2倍 | 研发比<2% + 无专利 |
| ② 规模壁垒 | 0-5 | 营收>同行均值3倍 | 营收<同行均值 |
| ③ 客户壁垒 | 0-5 | 高集中度+高转换成本 | 低集中度+易切换 |
| ④ 品牌壁垒 | 0-5 | 毛利率>同行均值+10pp | 毛利率<同行均值 |
| ⑤ 渠道壁垒 | 0-5 | 独家渠道+特许经营 | 无渠道优势 |
| ⑥ 政策壁垒 | 0-5 | 强牌照+标准制定者 | 无准入门槛 |

**定性结论**：≥20分=高壁垒(定价权强) | 10-19分=中壁垒(需持续投入) | ≤9分=低壁垒(易被侵蚀)

## 不可替代性判断（四维）

| 维度 | 输出 | 选项 |
|------|------|------|
| 替代品威胁 | 低/中/高/极高 | 现有替代品成熟度+新替代技术风险 |
| 客户转换成本 | 高/中/低/无 | 技术/数据/供应链/合同锁定 |
| 供给稀缺性 | 稀缺/较稀缺/一般/充裕 | 产能/资源/人才稀缺 |
| 生态粘性 | 强/中/弱/无 | 平台/网络效应/标准制定者 |

**综合结论**：不可替代 / 较难替代 / 可替代 / 易被颠覆

## 筹码结构稳定性（六维，0-12分）

| 维度 | 分值 | 2分条件 | 0分条件 |
|------|------|---------|---------|
| ① 股东户数趋势 | 0-2 | 连续下降→集中稳定 | 连续上升→分散不稳 |
| ② 限售股压力 | 0-2 | 解禁市值/日均成交<5倍 | >15倍 |
| ③ 前十大股东结构 | 0-2 | 多元公募/社保 | 员工平台/PE主导 |
| ④ 机构边际变化 | 0-2 | 机构↑+户数↓ | 机构↓+户数↑ |
| ⑤ 量价关系 | 0-2 | 缩量横盘/锁仓 | 放量滞涨 |
| ⑥ 套牢盘与杠杆 | 0-2 | 无套牢密集区+融资<3% | 高位套牢密集+融资>5% |

**定性结论**：≥9分=筹码稳定(新高品种) | 5-8分=中性(波段品种) | ≤4分=不稳(回避)

## 红旗信号（筹码相关）

| 信号 | 级别 | 条件 |
|------|------|------|
| 股东户数18个月翻倍 | 🔴 警告 | 户数当前/18月前 ≥ 2 |
| 限售股>40%+1月内解禁 | 🚨 致命 | 限售占比>40% 且 30天内有解禁 |
| 前5大股东为一致行动人 | 🔴 警告 | 公告披露一致行动关系 |
| 融资余额>流通市值5% | 🔴 警告 | 融资/流通市值 > 5% |
| 放量滞涨/量价背离 | ⚠️ 注意 | 换手率突增但股价不涨 |

## 综合评级

- 🟢值得关注 → `green`（评分≥7）
- 🟡谨慎观望 → `yellow`（评分4-6）
- 🔴回避 → `red`（评分≤3）
